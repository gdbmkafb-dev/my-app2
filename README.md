# SPLAT WARS - 2Dインクナワバリバトル 🦑🎨

HTML5 Canvas / CSS3 / JavaScript (Vanilla) で開発された、スプラトゥーン風のブラウザ対戦アクションゲームです。
外部ライブラリ・アセット不要（効果音・BGMもWeb Audio APIでリアルタイム合成）で動作します。

## 🎮 ゲーム概要
- **ルール**: 制限時間60秒のナワバリバトル！
  - 地面にインクを塗り合って、試合終了時により多くの面積を塗っていたチームの勝利！
  - 自色インクの上では高速移動（イカダッシュ）＆インクタンクとHPが急速回復。
  - 敵のインクの上では足を取られて移動速度激減＆スリップダメージ。
- **敵NPC (AI)**:
  - プレイヤーに向かってインクを撃ったり、ナワバリを塗り広げたりする敵AIが参戦！
  - 敵を撃破するとインクが爆散し、一定時間後にリスポーンします。

## 🔫 選択可能な4種類のブキ
1. **スプラシューター**: 連射力・射程・塗りのバランスが良い万能ブキ。
2. **スプラローラー**: 押し歩きで幅広く地面をベタ塗り！クリックで扇状に大量インク散布。
3. **スプラチャージャー**: クリック長押しチャージで超長距離貫通ショット！一撃必殺スナイパー。
4. **スプラブラスター**: 中距離で炸裂するインク爆発！物陰に隠れた敵もまとめて粉砕。

## 🕹️ 操作方法
### PC
- **移動**: `[W] [A] [S] [D]` または 矢印キー
- **照準**: マウス移動
- **ショット / 塗り**: マウス左クリック（長押し）
- **イカ潜伏**: `[Space]` または `[Shift]` キー（自色インク内で超高速移動＆インク回復）

### スマートフォン / タブレット
- **移動**: 画面左下のバーチャルスティック
- **ショット**: 画面右下の「SHOT」ボタン
- **イカ潜伏**: 画面右下の「潜伏」ボタン
